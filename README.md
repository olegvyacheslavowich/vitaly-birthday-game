# Забег Виталия

Мини-игра в подарок на 32-й день рождения Виталия: четыре уровня (Асбест, участок, дрифт, горка), в финале поздравление.

Играть: https://olegvyacheslavowich.github.io/vitaly-birthday-game/

Управление: тап по экрану (или пробел) — прыжок, на уровне «Дрифт» — удерживать палец.

Тексты, препятствия и поздравление настраиваются в объекте `CONFIG` в начале скрипта в `index.html`.
